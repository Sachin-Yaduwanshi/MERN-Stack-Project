# StayPulse – Hotel Booking and Management System

StayPulse is a full-stack web application designed to simplify hotel discovery, room booking, and property management. It provides separate functionality for guests, property owners, and administrators.

## 🎥 Project Demo

[▶️ Watch StayPulse Demo Video](https://drive.google.com/file/d/1XgsX3EoOt32RuRR1JmVEwhEHvkQzl4fj/view?usp=sharing)

## ✨ Key Features

- **Hotel Discovery:** Browse and explore available properties.
- **Room Booking:** Manage guest room reservations.
- **Guest Dashboard:** View bookings and manage profile information.
- **Property Owner Dashboard:** Manage properties, rooms, and bookings.
- **Admin Dashboard:** Manage users and property approvals.
- **Authentication:** Login and registration functionality.
- **Responsive Interface:** User-friendly web interface.

## 📚 Project Documentation

The documentation is organized into five phases:

1. **Ideation Phase:** Brainstorming, idea prioritization, problem statements, and empathy mapping.
2. **Project Planning Phase:** Project planning and milestones.
3. **Requirement Analysis:** Data flow diagram, functional and non-functional requirements, and technology stack.
4. **Project Design Phase:** Problem-solution fit, proposed solution, and solution architecture.
5. **Performance Testing:** User acceptance testing (UAT).

Explore the [`Documentation`](./Documentation/) folder to access the project documents.

## ⚙️ Running the Project

The project contains separate frontend and backend applications.

1. Open the `Project/StayPulse` directory.
2. Follow the setup instructions in the project README.
3. Configure the required environment variables using the provided `.env.example` files.
4. Install dependencies and start the backend and frontend using their respective instructions.
